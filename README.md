# YouTube Live Chat Verifier v2.0

A lightweight Tampermonkey userscript that checks whether your YouTube live chat messages are publicly visible.

## Features

- Automatic account detection
- Independent public chat verification
- Fast message verification
- Lightweight CSS status indicators
- No additional accounts or API keys required
- No external verification servers

## Status Indicators

- 🟢 Delivered
- 🔴 Not found
- 🟡 Checking...
- 🟡 Not confirmed
- ⚪ Verification failed

## Installation

1. Install Tampermonkey.
2. Open the `YouTube-Live-Chat-Verifier.user.js` file in this repository.
3. Click **Raw** and install the script.
4. Reload YouTube.

## Compatibility

Tested with Brave, Tampermonkey and uBlock Origin.

## Disclaimer

Verification is not always accurate. A missing message does not necessarily indicate a shadowban.
